# zmk-config-moNa2

<img src="keymap-drawer/mona2.svg" alt="moNa2 keymap">

## 現在のキーマップ

このキーマップは、公開動画「[【moNa2】自作キーボードの最終進化](https://www.youtube.com/watch?v=1kVLyGr4CoI&t=1677s)」で紹介された使い方を基にしたものです。以下では、キーを短く押す操作を「短押し」、押し続ける操作を「長押し」と呼びます。レイヤーキーの有効期間は長押し中に限られ、キーを離した時点で通常入力へ戻る仕組みです。

### レイヤー0：通常入力

一般的な英字配列（QWERTY）で文字を入力するレイヤーです。使用頻度の高い修飾キーとレイヤー切り替えを、通常の文字キーや親指キーの長押しへ割り当てています。

| キー | 短押し | 長押し |
| --- | --- | --- |
| `A` | `A`を入力 | `Control` |
| `Z` | `Z`を入力 | 左`Shift` |
| `/` | `/`を入力 | 右`Shift` |
| `;` | 上矢印 | レイヤー1で`;` |
| `"` | 下矢印 | レイヤー1で`"` |
| `,` | 左矢印 | レイヤー1で`,` |
| `.` | 右矢印 | レイヤー1で`.` |
| `P` | `P`を入力 | レイヤー6 |
| `-` | `-`を入力 | レイヤー7 |
| `Tab` | `Tab` | レイヤー5 |
| `Esc` | `Esc` | レイヤー5 |
| 左親指の`英数` | 日本語入力を切る | レイヤー4 |
| 左親指中央の`Space` | `Space` | レイヤー2 |
| 左親指の`かな` | 日本語入力を入れてレイヤー0へ戻る | レイヤー3 |
| 右親指の`Enter` | `Enter` | レイヤー1 |

### レイヤー1：記号

右親指の`Enter`を長押ししている間に使用します。丸括弧、角括弧、波括弧と、文章やプログラムで使う記号を右手側にまとめ、数字レイヤーと位置関係をそろえた配置です。デフォルト層で矢印になった`;`、`"`、`,`、`.`は、レイヤー1でも記号として入力できます。`;`と`"`は矢印と同じ位置、`,`と`.`は左手側で隣り合う位置です。

### レイヤー2：数字とファンクションキー

左親指中央の`Space`を長押しすると、レイヤー2を使用できます。短押しでは空白を入力し、判定時間を超える長押しではレイヤー2へ切り替わります。左手側の数字は電卓と同じ並びで、右手側の`F1`から`F12`も数字の並びです。

- 左手側：数字、四則演算記号、等号
- 右手側：`F1`から`F12`
- 右側中央の2キー：掛け算記号「×」と割り算記号「÷」

「×」と「÷」は、動画と同じくWindowsの数値入力を利用した設定です。Macでは同じ記号が入力されない場合があります。

### レイヤー3：移動とショートカット

左親指の`かな`を長押ししている間に使用します。`I`、`J`、`K`、`L`を矢印キーとして使えるため、ホームポジションから手を大きく動かさずにカーソルを移動できます。

| キー | 動作 |
| --- | --- |
| `I`、`J`、`K`、`L` | 上、左、下、右へ移動 |
| `U`、`O` | `Home`、`End` |
| `M`、`,`、`.` | `Delete`、`Page Up`、`Page Down` |
| `W`、`R` | 前後のタブへ移動 |
| `E` | 画面を撮影 |
| 左側エンコーダー | 音量を上下 |

左手側には、行頭・行末への移動や、ウインドウとデスクトップを移動するための修飾キー付き矢印も配置しています。

### レイヤー4：Bluetooth接続

左親指の`英数`を長押ししている間に使用します。右手上段の`Y`、`U`、`I`、`O`、`P`は、登録済みの接続先1、2、3、4、5にそれぞれ対応します。

- `/`：現在選択している接続先の登録を消去
- 右親指の`Esc`：すべての接続先の登録を消去

登録を消去すると再接続が必要になります。新しい接続先を登録し直す場合に限り、消去操作を使用してください。

### レイヤー5：マウス

トラックボールを動かすと自動的にレイヤー5へ切り替わります。レイヤー0へ戻る条件は、最後の操作から10秒経過するか、次の5キー以外を押すことです。手動で開く場合は、`Tab`または`Esc`を長押ししてください。

| キー | 動作 |
| --- | --- |
| `J` | 左クリック |
| `K` | 中央クリック |
| `L` | 右クリック |
| `M` | 戻る |
| `.` | 進む |

### レイヤー6：スクロール

`P`を長押ししながらトラックボールを動かします。上下の動きで縦方向、左右の動きで横方向へスクロールでき、左側エンコーダーを回した場合は縦方向へ移動します。

### レイヤー7：タブ操作

`-`を長押ししながらトラックボールを動かすと、ブラウザーのタブを操作できます。操作中はポインターが移動しません。

| トラックボールの方向 | 動作 |
| --- | --- |
| 左 | 前のタブへ移動 |
| 右 | 次のタブへ移動 |
| 上 | 新しいタブを開く |
| 下 | 現在のタブを閉じる |

### レイヤー8：仮想デスクトップ操作

`O`と`P`を同時に短押しすると`Alt＋Tab`を実行します。2キーを押したままトラックボールを動かすと、仮想デスクトップを操作できます。操作中はポインターが移動しません。

| トラックボールの方向 | 動作 |
| --- | --- |
| 左 | 前の仮想デスクトップへ移動 |
| 右 | 次の仮想デスクトップへ移動 |
| 上 | タスクビューを開く |
| 下 | 使用中のウインドウを次の仮想デスクトップへ移し、そのデスクトップへ移動 |

レイヤー3、7、8のショートカットは、動画と同じWindows向けの組み合わせを含みます。通常レイヤーの`Command`キーはMac向けに変更済みですが、ショートカットの一部はMacで同じ動作にならない場合があります。

## COROPITを使用する場合

COROPITを使用する方は以下のようにコードを編集してください。

mona2_r.overlay

修正前
```
  trackball_central: trackball_central@0 {
        status = "okay";
        compatible = "pixart,pmw3610";  //トラボセンサ用のドライバとバインド
        reg = <0>;
        spi-max-frequency = <2000000>;
        irq-gpios = <&gpio0 2 (GPIO_ACTIVE_LOW | GPIO_PULL_UP)>; //P0.02を指定(MOTION)
        cpi = <600>;
        //swap-xy;
        //invert-x; //COROPIT版ではコメントアウトを外す
        //invert-y; //COROPIT版ではコメントアウトを外す
        evt-type = <INPUT_EV_REL>;
        x-input-code = <INPUT_REL_X>;
        y-input-code = <INPUT_REL_Y>;
    };
};

```
**修正後**
```
  trackball_central: trackball_central@0 {
        status = "okay";
        compatible = "pixart,pmw3610";  //トラボセンサ用のドライバとバインド
        reg = <0>;
        spi-max-frequency = <2000000>;
        irq-gpios = <&gpio0 2 (GPIO_ACTIVE_LOW | GPIO_PULL_UP)>; //P0.02を指定(MOTION)
        cpi = <600>;
        //swap-xy;
        invert-x; //COROPIT版ではコメントアウトを外す
        invert-y; //COROPIT版ではコメントアウトを外す
        evt-type = <INPUT_EV_REL>;
        x-input-code = <INPUT_REL_X>;
        y-input-code = <INPUT_REL_Y>;
    };
};

```
